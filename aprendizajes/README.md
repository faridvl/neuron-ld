- [interfaces-salientes-dos-pinos-contratos.md](interfaces-salientes-dos-pinos-contratos.md): canales CAI y gateway de Informatica, lo que respondió dev en POS-11/19/24/26, Bruno CLI con secretos, y diseño de eventos de negocio y reintentos.
- [acentos-stdin-proceso-hijo-iis.md](acentos-stdin-proceso-hijo-iis.md): tildes dañadas al pasar texto por stdin de un sitio IIS a un proceso hijo (Runner de integraciones).
