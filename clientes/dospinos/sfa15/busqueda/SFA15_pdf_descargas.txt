=====P3=====
1. Descripción General 
Modelo de Integración Sincrónica en tiempo real. 
Esta integración tiene como objetivo implementar una integración que permita procesar 
las solicitudes de autorización de venta financiada provenientes de los sistemas origen de 
Dos Pinos, utilizando Informatica Cloud – Application Integration (CAI) como capa de 
integración y orquestación para el consumo de los servicios expuestos por SFA. 
2. Actores y Sistemas Involucrados 
Sistema Rol 
SFA  Destino Proveedore de api   
informática  Orquestación, validaciones, reglas de 
negocio, exposición de Endpoint API y 
registro de trazas. 
LDCOM Sistema consumidor que dispara eventos 
programados para consumir la API expuesta 
por informática. Controla la frecuencia de 
ejecución. 
Monitor Integral Correlación de transacciones con ID único. 
 
3. Alcance Funcional 
Endpoints a utilizar: 
• End Point: https://usw3-cai.dm-us.informaticacloud.com/active-
bpel/rt/p_SFA15_Autorizacion_Venta_Final 
• Swagger: https://usw3-cai.dm-us.informaticacloud.com/active-
bpel/rt/p_SFA15_Autorizacion_Venta_Final?swagger  
4. Patrón y plataforma de integración  
• Patrón: Sincrónico en tiempo real 
• Plataforma: informática Cloud 
• Middleware único: informática Cloud (cumpliendo regla corporativa). 
• Observabilidad: Obligatoria, implementada con Monitor Integral (API de control)

7. Pruebas 
• Unitarias: Validación de extracción desde SFA y formato JSON. 
• Integración: Llamada a endpoint SFA desde Informática. 
• Seguridad: Validación TLS 1.2 y API Key funcional. 
8. Riesgos y Mitigaciones 
Riesgo Mitigación 
Volumetría superior a la estimada Habilitar paginación/lotes, compresión y 
ventana de proceso ampliable. 
Intermitencia de LDCOM al consumir API Reintentos exponenciales e idempotencia 
en Integration Hub. 
Exposición de credenciales Uso de bóveda y API Key cifrada.
