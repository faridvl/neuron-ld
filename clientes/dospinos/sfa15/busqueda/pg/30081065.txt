Guardar exoneraciones por cliente
Módulos: 🛠️ Site admin | 💵 POS
Se pueden guardar múltiples exoneraciones por cliente.

Se valida la fecha de vigencia de exoneraciones guardadas

Se aplican las exoneraciones en los CAByS que correspondan.

Criterios de aceptación
Al agregar una nueva exoneración, se valida el documento (validez y fecha) ante Hacienda.

Si la API de hacienda está caída, muestra una advertencia y no permite agregarlo.

Al agregar una nueva exoneración, se aplican las tarifas reducidas.

Si el cliente ya trae una exoneración guardada:
Se valida la fecha de vigencia (y muestra advertencia si está vencida)
¿Se debe borrar?


No se valida el documento con hacienda de nuevo.


La exoneración solo se aplica a los CAByS correspondientes.

Validaciones de MAG/Hacienda
Módulos: 💵 POS
Validar la inscripción en hacienda/mag al agregar un nuevo cliente de factura electrónica en el documento.

Criterios de aceptación
Un cliente existente no se valida.

Se valida que el cliente esté inscrito en Hacienda al agregarlo en una factura electrónica.

Si el cliente no está inscrito no se puede agregar como factura electrónica

Si el cliente está inscrito en MAG, se aplican las tarifas reducidas a los productos que aplican (véase 3. Tributario )

Si la API de hacienda está caída, muestra una advertencia
No permite agregar el cliente (confirmar con Dos Pinos).

No aplica ninguna tarifa reducida.
